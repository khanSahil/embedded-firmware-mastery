# Track 1 Dependency Graph

## Principle

Track 1 is not three independent tracks. Concepts, Design, and Labs are synchronized dimensions of the same mastery journey.

## Relationship

Concepts

- provide technical understanding
- define prerequisites
- identify limitations

        |
        v

Design

- applies concepts to architecture
- introduces tradeoffs
- defines implementation approach

        |
        v

Labs

- implement on hardware
- validate assumptions
- expose missing concepts

        |
        v

Feedback returns to Concepts and Design.

---

## Ownership Rule

Each sub-track owns its detailed progress files.

Integration tracks relationships and dependencies only.

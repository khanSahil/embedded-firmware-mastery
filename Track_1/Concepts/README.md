# Track 1 - Concepts

This area owns technical curriculum, conceptual progress, mastery evidence, and revision tracking for Track 1.

Responsibilities:
- C language and embedded fundamentals
- MCU / CPU / memory concepts
- compiler and language semantics
- debugging concepts
- mastery validation
- revision / reinforcement tracking

Canonical files:
- `Curriculum.md` — what should be learned and in what sequence
- `Progress.md` — current conceptual position and historical checkpoints
- `Mastery-Ledger.md` — demonstrated capability and evidence
- `Revision-Queue.md` — subtle or weak areas to reinforce later

Concept work establishes readiness for Design and Labs. Cross-stream relationships are maintained under `../Integration/`, while `../Active-Context.md` provides the short current dashboard used by every Track 1 chat.

# Track 2 – Embedded Linux / Linux Device Drivers Curriculum

Status: `NOT_STARTED`

Track 2 begins only after Track 1 is completed and Track 2 is selected as the next major program.

## Purpose

Build deep Embedded Linux and Linux Device Driver capability, including system programming, kernel internals, BSP/bring-up, drivers, boot flow, Yocto, debugging, production behavior, and update/security concerns.

## Platforms

- Linux PC / VM and QEMU for early concepts and experiments
- i.MX 8M Plus EVK as the primary real-hardware platform when board/BSP/driver work is needed

## Planned progression

1. Linux system programming
2. Linux kernel architecture and internals
3. Boot ROM → SPL → U-Boot
4. Device Tree
5. Kernel modules
6. Character/platform and related driver models
7. Interrupts
8. Concurrency and synchronization
9. Memory management
10. DMA and cache/coherency considerations
11. BSP and board bring-up
12. Kernel debugging and tracing
13. Yocto / Buildroot concepts and BSP construction
14. Userspace integration and systemd
15. Networking
16. Secure boot / security concepts
17. OTA / field update architecture
18. Production failure analysis and recovery
19. End-to-end capstone integrating boot, kernel, driver, userspace, and build-system layers

The exact section breakdown may evolve when Track 2 starts; do not mark any topic complete before it is actually taught and assessed.
